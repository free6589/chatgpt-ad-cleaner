ChatGPT Ad Cleaner

A small browser add-on that hides the upgrade ads on ChatGPT. Install it once, then forget about it.

⬇ Install

Requires the free Tampermonkey extension. Two minutes, no account needed.

What gets removed

  • The “Get offer” button at the bottom of the sidebar
  • The “Free offer” button in the top-right corner
  • The “Free” label under your name
  • The “ChatGPT can make mistakes…” line
  • The upgrade card above the message box
  • The “upgrade for more uploads” row in the + menu — “Upload from computer” comes back
  • And it switches the Think button on in eligible chats, with experimental support for project chats

How to install

  1. Install Tampermonkey for your browser (Chrome, Edge, Firefox or Safari).
  2. Come back to this page and click the green Install button.
  3. Tampermonkey shows a page with the script — click Install.
  4. Open or refresh chatgpt.com. Done.

Good to know

The script never touches your chats, your message box or the sidebar. It only hides advertisement blocks.

It works whatever language your ChatGPT is set to — English, Chinese, Spanish, French, German, Portuguese, Italian, Japanese, Korean, Russian and more.

It also cannot change the upload limit itself — that number lives on OpenAI’s servers. It only puts the normal “Upload from computer” item back so the menu is usable again.

To check it is running, press F12, open the Console and type document.documentElement.dataset.chgptScript.
